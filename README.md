# Sarve Mandegar — Coming Soon

A cinematic, Persian RTL launch page for تندیس نگاران سرو ماندگار.

## Run locally

```bash
npm install
npm run build
npm run start
```

## GitHub

Create a new repository on GitHub, then add this project as the repository contents. Keep the uploaded logo at `public/images/file_00000000292c8243af3cf25148e480ca.png` so the official mark remains available.

## Vercel

Import the GitHub repository into Vercel. The project is configured for Next.js, so Vercel will detect the framework and build settings automatically. No environment variables or database are required.

## Custom domain

In the Vercel project, open **Settings → Domains**, add your domain, and follow the DNS records Vercel provides. Once DNS is verified, the site will be available on the custom address.
